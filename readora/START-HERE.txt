READORA — RUN ON YOUR WINDOWS LAPTOP

1. Install Node.js 24 LTS if you do not have it.
2. Extract this ZIP. Open the readora folder in VS Code.
3. Open Terminal > New Terminal (PowerShell).
4. Run these commands:

   npm install
   Copy-Item .env.example .env
   npm run dev

5. Open http://localhost:5173 in your browser.
